## 四、待关注事项

1. **缺陷无跟踪**：P0 修复仅记录在 commit message，无 Issue/PR 留痕。建议启用 GitHub Issues 或维护 `CHANGELOG`，便于回溯与责任人确认。
2. **高变更量回归风险**：两周内大规模重构 + 多 App 并行，回归面大，尤其**嵌入式 widget 承载层**与 **PLC 联动**部分需重点回归。
3. **新建 App 未稳定**：`PopPick`、`LogPlot` 尚处起步阶段，建议待稳定后再并入主发布流。
4. **关键资源随提交变更**：`myDesigner/`、`res/` 含 `data2.json`（约 1.3MB 场景）等，打包必须一并带出，否则运行态画面为空。
5. **DEBUG 开关一致性**：已统一 DEBUG 开关（10-30），需确认各模块 `RACK_DEBUG_SCENE` 等环境变量行为一致，避免热路径误打印影响性能。
