## 修：网线 1~8 位置错（`on_item_changed` / `change_end_pos`）

- 现象：`my_plc_safety.on_item_changed` 勾选节点后，网线 1~8 的终点落点不对。
- 根因：适配层对外是**旧 page 口径**，但 `change_end_pos` 把 page 坐标**原样**传给了
  `set_page_head_end`，而 DesignerV2 的这个 setter 收的是**原生场景**坐标 ——
  终点被又「轴交换 + 4 倍缩放」了一次。起点同理会偏。
- 修法（`safety_scene_adapter.py`）：
  * 新增正投影 `_to_scene_point(page) = (-y*k, -x*k)`（与 `_to_page_point` 互逆）；
  * `change_end_pos`：起点从 `_page["head_pos"]` 取**原生**值（新增
    `_native_endpoint()`，不再用映射过的 `get_scene_head_pos`），终点 page→scene 映射；
  * `rotate_to_ang` / `get_angle` 一并改成 page 口径 ↔ 原生互转（`set_page_angle(-ang)`），
    否则维修区/安全门的开门动画会反向。
- 验证（旧包 vs V2 同操作）：
  * 勾 2 个节点后 `网线1` 终点 = 目标节点中心，Δ=(0.002,0.001)（page 单位，来自
    `_page` 3 位小数 rounding）；
  * `change_position(565.7,2409.8)`（外部网络）→ `topLeft=(565.700,2409.800)` 两边一致；
  * `rotate_to_ang(-90)`（维修区_安全门）→ `get_angle()=-90`、bbox 完全相同；
  * 勾 3 个节点 + `on_item_changed` + 切「维修区工作站」后整窗截图
    **逐字节相同**（可看到绿色网线穿过「上架工作站X4」卡片）。
