# 2026-11-09

## packTool.py：warn 扫描误报「隐藏导入找不到」
- 现象：`工具集V3.0` 打包返回码 0、`dist/工具集V3.0.exe`(296MB, 00:22) 已生成，却报 numpy/pandas/pyarrow「隐藏导入在打包环境里根本找不到」，提示换 venv 解释器。
- 根因：`_scan_warn_files()` 用 `found == name or found.startswith(name + ".")` 判致命。warn 里的 `numpy._core.zeros`（176 条）、`pandas.core.internals.Block`、`pyarrow._cuda/gandiva` 是包内 re-export 属性 / 可选组件被 PyInstaller 静态分析误判成子模块，不是顶层包缺失；精确顶层 missing 为 0 条。venv 里三包都在，spec 前置自检 `find_spec` 通过，PYZ-00.toc 收了 numpy 137 / pandas 291 / pyarrow 33 项。
- 修复（最小改动）：致命判定收紧为「顶层包精确 missing」，新增 `_unresolvable_roots()` 在打包解释器里 `find_spec` 二次复核（复核失败仍按 warn 报错，宁可误报不静默放过）；包内子项噪声单独计数并忽略，日志把「真正其它缺失模块」单独列出。
- 回归：真实 `warn-temp_工具集V3.0.txt` → 致命清单 `[]`、179 条子项噪声被忽略、152 条其它缺失；人造 warn 中真缺包仍被拦截、已安装的 numpy 被降级。`py_compile` 通过。
- 约定：以后 `missing module named <pkg>.<sub>` 一律不判「环境错」；只有顶层包在打包解释器里也 `find_spec` 不到才算致命。改 packTool.py 后需重启打包工具 GUI 才生效。本次无需重新打包。
