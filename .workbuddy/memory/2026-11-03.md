## 复制粘贴 widget_element 崩溃（AttributeError: 'NoneType' has no attribute 'x'）

**现象**：选中控件图元 → 复制 → 粘贴，抛
`paste → setPos → __check_position_change → update_boundingRect → mapToScene → Transform.map` 崩在 `point.x()`。

**根因（三段叠加）**
1. `widget_element.clone()` 只拷了尺寸，**没拷几何四角**（`_head_pos/_end_pos/_topRight/_bottomLeft` 等）。
   `widget_element()` 默认走 `constructed_by_draw=True` 分支，`_head_pos` 停在 `None`，
   于是 `mapToScene(None)` → `Transform.map(None)` → AttributeError。
   `rect_element.clone()` 是拷四角的，widget 那份是后来手写时漏的。
2. `rect_element.update_boundingRect()` 对四角为 None 没有任何兜底，异常直接从 Qt 虚函数
   （`QWidget::event` 覆写）里抛出来，PySide6 只打印 traceback，粘贴就此中断。
3. 粘贴命名 `default_name_args` 缺 widget/checkbox 分支，被前面的 `rect_element` 分支截走，
   控件粘贴后叫“矩形_N”（绘制时叫“控件_N”）。

**修复**
- `widget_element.clone()` 补 `set_head_pos/set_end_pos/set_center_pos` + 四角 `QPointF` 拷贝。
- `rect_element.update_boundingRect()` 四角任一为 None 时按 `scene_size` 本地重建（兜底，不再崩）。
- `rect_element.clone()` 的 `cloned = rect_element()` 改成 `self.__class__()`——
  checkbox_element 没有自己的 clone，写死基类会让“复制复选框”粘出矩形。
- 粘贴命名补 `控件_ / 复选框_` 分支，**必须排在 `rect_element` 之前**。
- 粘贴收尾补 `set_widget_readonly(mode != Run)` + `set_widget_visible(True)`：
  粘贴走 `completed(True)`（反序列化分支）不会被 `addItem` 的交互式创建逻辑接管，
  不补这一步粘出来的控件只剩占位框（画布绘制的控件是真实控件）。
- `copy_selected` 里 `print(f"顶层复制项：…")` 改成 `debug_log`（地址 dump 属噪音）。

**验证**：控件/复选框/矩形/文本/组（含控件子项）复制粘贴均正常，连续粘贴两次位置递增；
粘贴控件 `has_widget_layer=True`、layer 几何落在场景内；注解 100% 仍保持，
`verify_render` / `verify_property_panel` / `verify_group_tab_cycle` 全通过。

## 运行态点击 rect 显示 id：已修复

**现象**：运行态点 rect 图元会显示红色 `id[parent_id]`，运行态本不该选中图元。

**根因**（三处叠加）：
1. `base_element.paint()` 的画 id 条件是 `__selected and __invisible`（与模式无关）。
2. `myGraphicsScene.mousePressEvent`（1922）的 `single_select_handle()` **没有 Design 门控**
   （`mouseDoubleClickEvent` 是包了的），运行态点击照样走选中分支。
3. "运行态不可选"唯一靠 `__selectable=False`，只有 `toggle_sence_mode()` 会拉这道闸；
   而运行窗口（`rack_stores_widget.py` / `rack_global_paras_widget.py` / `rack_store_widget.py`）
   都是直接 `set_scene_mode(Run)` 进运行态，且常在**图元加载之前**调用，闸根本没拉。

**修复**（三层）：
1. `myGraphicsScene.mousePressEvent` 选中分支包 `if self._mode == SceneMode.Design`。
2. `QuadTreeScene.set_scene_mode` 统一对齐：Run → `set_selected_anyway(False)` + `set_selectable(False)`；
   Design → `set_selectable(True)`（覆盖已加载图元 + 设计态遗留选中）。
3. `SceneManager.addItem` 兜底：Run 态进来的图元直接置不可选（覆盖"先 set_scene_mode(Run) 后加载"时序）。
4. 顺手修 `set_selected_anyway` 的死参数签名 `(self, child, state)` → `(self, state)`（全项目无旧调用方）。

**踩坑记录**：手工构造测试图元必须 `setID(n)` 分配唯一 id——`id()` 只认 `setID`，
两个默认图元 id 都是 0 会在 `m_items` 里互相覆盖，测试会假失败（sorted 里只剩一个）。
`myGraphicsScene.addItem` 会把 `sceneBoundingRect` 为空的图元当"场景外"丢弃，
构造图元后必须补 `update_boundingRect()`。

**验证**：运行态点击 rect 不选中/不画 id；设计态点击正常选中；Run↔Design 往返清遗留选中；
Run 态新增图元兜底不可选；checkbox 运行态事件路由命中 + toggle 翻转正常；
`verify_render`（1614 图元逐像素一致）/ `verify_property_panel` / `verify_group_tab_cycle` 全过。
