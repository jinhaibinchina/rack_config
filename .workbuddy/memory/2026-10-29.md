# 2026-10-29

## 修复：PyInstaller 打包后 exe "打不开"

**现象**：dist/rackConfigV6/rackConfigV6.exe 双击无窗口。带 console 直接跑能看到：
`main.ui` / `rcd.qss` / `Failed to load UI file: Unable to open/read ui device`，随后退出。

**根因**：路径少一层 `res`。
- `res/resource_manager.py::_get_base_path` 打包时直接取 `Path(sys._MEIPASS)`，
  再拼 `App/ui/main.ui` → `<_MEIPASS>/App/ui/main.ui`；
- 但 spec 的 `datas=[('res','res')]` 把资源放到了 `<_MEIPASS>/res/App/ui/main.ui`；
- `App/load_ui.py` 里 UI 加载失败会 `sys.exit(1)`，所以表现为"双击没反应"。

**修复**：
1. `res/resource_manager.py::_get_base_path` 改成多候选探测，以 `App` 子目录是否存在判定：
   `<MEIPASS>/res` → `<MEIPASS>` → `exe同目录/res` → `exe同目录`，都没有才回退 `<MEIPASS>/res`。
   源码运行仍返回 `Path(__file__).parent`（即 `res/`）。
2. `myDesigner/myQuadTreeScene.py::SceneSerializer._resource_dirs` 增补
   `<MEIPASS>/res` 与 `<MEIPASS>/res/myDesigner` 两个候选（data2.json 若打进 res 下也能找到）。
3. `App/load_ui.py` 三处 UI 加载失败日志额外打印 `ui_file` 及 exists，便于下次定位。

**验证**：重新 `pyinstaller rackConfigV6.spec --noconfirm` 后启动，窗口标题
"料架PLC配置工具 V6.0.0"，进程 Responding=True。

**注意**：
- 运行期真正用的只有 `res/resource_manager.py`；`res/designer_resource_manager.py` 只被
  `Designer/Core/*`（独立设计器）引用，`myDesigner/resource_manager.py` 目前无人 import。
- 仓库里当前**不存在** data2.json（myDesigner/ 和整个 D:/rack 都没有），所以运行时场景是空的，
  `rack_stores_widget` 会打印"场景为空"提示。要带场景得把 data2.json 放进 myDesigner/ 并加进 datas。
- `res` 作为 datas 打包时会把 `res/*.py`、`res/__pycache__` 一起拷进 `_internal/res`（资源不该带代码），
  精度要求高时可把 datas 收窄成 `res/App` 与 `res/myDesigner`。
