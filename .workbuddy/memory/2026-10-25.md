## 修复迁移后主界面空白
- 根因：uic_compat 中 `_UiLoader(baseinstance)` 误将 baseinstance 传给 QUiLoader 的 parent 参数，_baseinstance 恒为 None，加载器另建了一个未显示的 QMainWindow
- 修复：__init__ 正确保存 _baseinstance 实例属性；并加 _install_central_widget 兜底 setCentralWidget（QUiLoader 不会自动设置）
- 验证：ui is mw=True、centralWidget 正常、12 个 ui 全部加载 OK、MainWidget OK

## 灯带颜色/频率（rack_store_model.py set_light_color）
- 场景每个仓位只有一个 rect 型「灯带」本体，无分色图层 → 颜色用 set_fill_color/set_color 改本体
- 颜色：红 #FF0000 / 绿 #00FF00 / 蓝 #0000FF / 黄 #FFFF00 / 灰 #808080（LightColor 枚举）
- 频率：steady 常亮 / 1hz(半周期500ms) / 0.5hz(半周期1000ms)（新增 LightFreq 枚举）
- 闪烁由每仓位懒创建的 QTimer(PreciseTimer) 切换 set_visibility 实现
- API：slot.set_light_color(color, freq)；model.set_light(r,s,color,freq)；RackSlotStatus 新增 light_freq 字段
- hide_all_state_layers 会先 turn_off_light 停表；'off' 关灯隐体
- 实测：1Hz≈1.05s周期、0.5Hz≈2.07s周期、常亮不翻转
