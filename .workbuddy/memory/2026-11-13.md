## CoreQGraphics 设计器：图元锁定（locked / 双同心圆标记）
- 需求：按用户截图，锁定图元左下角常显「2 个同心圆 + 中心点」，且**设计模式
  下不能移动 / 旋转**（顺带禁缩放），运行态不受影响。
- **数据口径**：`locked` 是可选顶层字段，缺省 False；`BaseItem.is_locked()`
  读 `_page.get`，`set_locked(True)` 走 `set_page_field`，**解锁直接删键**，
  回到存量记录原貌 → page_1 1618 图元 round-trip 零改动。旧 Core
  `from_dict` 只读已知键，遇到 locked 会忽略（能打开，但旧编辑器保存会丢字段）。
  别和 `translate_locked()` / `pose_locked()`（有父对象时锁平移）混淆。
- **拦截层级刻意只放在交互层**，不动 `set_page_center` / `moveBy` 等底层 API：
  组刚体联动、撤销重建、运行态零污染改图元都还要用它们。
  `GraphicsScene.pose_blocked(item)` = 自身锁定 **或任一下代锁定**（防拖父组
  带走锁定成员），`editable_pose()` 过滤；`set_items_locked(items, value)`
  批量写 + `emit_items_changed` + `refresh_movable`。
  覆盖：跟手 `begin_follow`、方向键 `_nudge_targets`、T 抓手 `_grab_item_for_point`
  / `_align_grab_to`、拖角 `_resize_item` + `resize_item_about`、`+/-` 与 `[ ]`
  快捷键、对齐 / 分布 / 旋转支点设置复位、属性面板 X/Y/W/H/旋转置灰、
  `ItemIsMovable` 兜底。删除 / 复制 / 改名 / 改外观仍允许；副本继承 locked。
- **绘制**：`g_view._draw_lock_badges()` 在 `drawForeground` 里切回视口像素，
  位置取 `sceneBoundingRect().bottomLeft()` + (7,-7)，外圈 r=6 / 内圈 r=3 /
  中心点 r=1.1 + 浅白底，恒定屏幕大小；只用 `scene.all_items()` 遍历，
  不占 viewportMargins、不进图元 paint（运行态 / RuntimeView 绝不会画）。
- **入口**：编辑菜单 / 画布右键 / 图层树右键 / 工具栏 + 属性面板「常规」页复选框，
  Ctrl+L 锁定、Ctrl+Shift+U 解锁；`_do(lock/unlock)` 走 `scene.set_items_locked`
  + `_after_edit()`（撤销栈里的整页快照天然带 locked）+ `_on_selection_changed()`
  重建面板。属性面板用 `_pose_widgets` 保存「未锁定时可用状态」快照同步置灰，
  **不在 toggled 信号里重建面板**（避免销毁正在发信号的控件）。
- 门禁：主门禁 6.13（17 条：字段 round-trip、几何零影响、对齐/分布/支点/缩放
  过滤、组保护、movable gate、落盘重载持久化）171 项；UI 门禁 8.32（17 条：
  标记像素 + 解锁还原 + 运行态不画 + 菜单快捷键 + 跟手/nudge/手柄/`]` 旋转/
  面板置灰 + 撤销重做恢复 + 常规页复选框直连）388 项。7 个脚本全 `EXIT=0`、无 FAIL/warn，

## CoreQGraphics 绘制态 T 吸附修复（完成）
- 根因 1：工具箱按钮激活绘制后焦点留在 Dock，T 送不到 `GraphicsView.keyPressEvent`；
  `set_draw_tool()` 现在收回画布焦点。
- 根因 2：增删图元只把吸附点表置脏，绘制第一点前按 T/画十字可能还在用旧表；
  `set_draw_tool()` 主动刷新，`_ensure_snap_table()` 在红十字、按 T、落点前兜底同步。
- 根因 3：旧 `_snap_scan_exclude()` 在绘制态也排除「已选中图元」特征点，而刚画完的
  图元默认选中，导致无法从已有角点起画；绘制态改为只排除正在画的 `commit=False`
  临时图元自身点，非绘制态语义不变。
- 根因 4：按 T 只 warp 光标/刷预览，真正落点仍用原始坐标；`_draw_page_point()` 现在
  直接吃与红十字同一份 `aim` 结果，第一点/后续点一致，预览、落点、正交同一入口。
- 门禁：`tools/verify_core_qgraphics_draw_snap.py` 覆盖脏表、选中图元起画、未开门控自由落点、
